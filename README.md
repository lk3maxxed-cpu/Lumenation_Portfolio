# Lawrence Kirk / Lumen the SIM portfolio

Static portfolio. Open `index.html` through any static web server; no build or package installation is needed.

## Content

- TAME JOY is the featured exhibition, with 16 photographs, approved exhibition text, and a downloadable PDF.
- Exhibition documentation follows in reverse chronological order, followed by group shows, screenings, studio work, artist statement, CV, and contact.
- Existing project text, artwork, and film destinations have been retained. The malformed Slanted Grove CV entry has been repaired.
- The original Ferrum typeface is retained for titles. Text uses a readable system serif, with small system sans-serif labels.

## Images

Images previously embedded in HTML are now cacheable WebP files in `assets/archive`. TAME JOY web derivatives are in `assets/tame-joy`. High-resolution submission originals remain outside this repository and are unchanged. Original legacy files in `assets` remain available.

## Interaction and accessibility

The exhibition index uses normal anchor links. The TAME JOY gallery supports click or keyboard activation, previous/next controls, arrow keys, and Escape to close. Mobile navigation exposes its expanded state. The content remains readable without JavaScript, and reduced-motion preferences are respected.

## Validation

Reviewed at desktop and 390 px mobile widths. Checked gallery navigation, mobile menu, local asset paths, section destinations, unique IDs, and whitespace errors. No horizontal overflow at the tested mobile width.
